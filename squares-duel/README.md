# Squares Duel

Public browser build for [Squares Duel](https://le0n-97.github.io/squares-duel/), hosted in the squares-duel/ directory of [le0n-97/le0n-97.github.io](https://github.com/le0n-97/le0n-97.github.io).

The former website has closed. Its API continues to provide the database, room service, chat and username/password accounts used by this GitHub Pages frontend. Sign-in is required to create or join a room, spectate or chat. Guest play is disabled. Sign in with the same account to reconnect to an existing room on another device.

This directory contains browser assets only. Server code, account data, game records and credentials are not included. The SCOWL dictionary license is available in [dictionary-license.txt](dictionary-license.txt).

The complete application source is maintained in [squares-duel-src](https://github.com/le0n-97/le0n-97.github.io/tree/main/squares-duel-src). GitHub Actions checks source changes and regenerates this directory before publishing. Keep the existing homepage and other repository files when publishing updates.

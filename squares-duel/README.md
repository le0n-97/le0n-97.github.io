# Squares Duel

Public browser build for [Squares Duel](https://le0n-97.github.io/squares-duel/), hosted in the squares-duel/ directory of [le0n-97/le0n-97.github.io](https://github.com/le0n-97/le0n-97.github.io).

The original game remains available at [its existing address](https://squares-duel-oct15.sacred-rhea-9950.chatgpt.site/). Both entrances use the same room service and scoring. Browser identities are stored separately on each website; join with the same room code to play together.

This directory contains browser assets only. Server code, game records and credentials are not included. The SCOWL dictionary license is available in [dictionary-license.txt](dictionary-license.txt).

Website updates are exported from the maintained private working copy and copied into this directory. Keep the existing homepage and other repository files when publishing updates.

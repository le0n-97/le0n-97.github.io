# Squares Duel

Public browser build for [Squares Duel](https://le0n-97.github.io/squares-duel/), hosted in the squares-duel/ directory of [le0n-97/le0n-97.github.io](https://github.com/le0n-97/le0n-97.github.io).

The former website has closed. Its API continues to provide the database, room service, chat and username/password accounts used by this GitHub Pages frontend. Guest play remains available. Sign in with the same account to reconnect to an existing room on another device.

This directory contains browser assets only. Server code, account data, game records and credentials are not included. The SCOWL dictionary license is available in [dictionary-license.txt](dictionary-license.txt).

Website updates are exported from the maintained private working copy and copied into this directory. Keep the existing homepage and other repository files when publishing updates.
